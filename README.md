# E-Commerce Website – Full Stack Workshop Assignment

This project is part of the **5-Day Full Stack Development with Python & GenAI Workshop**, organized by Full Stack Experts Academy, an initiative of Innomatics Research Labs.

## About the Project

A customized e-commerce website developed as part of the Day 4 practical assignment. The project focuses on modifying an existing online shopping website and improving its product presentation.

## Customizations Made

- Updated product images.
- Modified product titles.
- Updated product descriptions.
- Changed product prices.
- Customized product details and presentation.
